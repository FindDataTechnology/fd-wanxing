# 萬星是独立项目，部署独立分阶段走

萬星（Agent 服务的对外运行与服务平台）在 paas 内长大（门面 ADR-0014、registry 归属
ADR-0015 均为 paas 侧决策），2026-10-04 定案升格为**独立项目与产品条线**：本仓、自有
openspec 治理、自有发布线。部署独立按阶梯分阶段执行——**L1 品牌面**（wanxing 自有
域名 + 公共目录/文档门面）与 **L2 部署面**（facade+观测面自有部署单元，不再随壹座
gateway 滚动）现在做；**L3 交付面**（可对外私有交付的完整产品）不现在做，但以「借用
契约」纪律保持可达；代码迁移不做一次性大搬（facet S1 拆分漏拷/envFrom 前科在册）：
新生物（观测面、wanxing-web）直接生于本仓，facade 于 L2 拆面时迁入，runner 随后；
openspec 治理随代码走，in-flight 的 paas 侧工作在原地做完、边界处 fork specs，不回改
历史归档。

_背景_：此前 paas 侧曾倾向「萬星门面寄宿壹座、独立域名收益存疑」——被「萬星是核心
产品线、要独立运行」的产品定位推翻。母仓相关 ADR：paas ADR-0014（门面/调用键/边界
结算）、ADR-0015（registry 是谦面组件）。
