萬星副驾 · 一行接入示例页

本页就是接入方：一个 <script> 标签挂载这副驾，宿主不写任何 postMessage 协议。本页已挂在 /host-demo.html?line=<线id>——换 line 参数即可试不同线。

1. 最小接入：一个标签

<script src="https://wanxing.finddatatech.cloud/copilot.js"
        data-line="lex" async></script>

必须是经典脚本（不要加 type="module"）；data-accent="#rrggbb" 可覆盖线配色，data-open="1" 可让 widget 初始展开（缺省收起，只剩右下角圆钮）。

2. 可选钩子：宿主身份 / 页面上下文 / 页面动作

window.WanxingCopilot = window.WanxingCopilot || {};
WanxingCopilot.identify = () => ({ token });          // 每回合调用，可返回 null
WanxingCopilot.context  = () => ({ page, entity });   // 就绪时 + hashchange/popstate 时调用
WanxingCopilot.intents  = { navigate: (arg) => router.push(arg) };
WanxingCopilot.pushContext = () => {};                // SPA 用 pushState 跳转后手动调一次
WanxingCopilot.onEvent = (type, detail) => {};        // 可选：观察协议，不用自己实现
钩子不提供时
identifywidget 用自身梯队：匿名（线已开）或登录升级（会点名登录到哪个平台）
context不推页面上下文，agent 只看到用户输入
intentsagent 的页面动作提议只渲染成普通问询卡，不会出现可执行按钮

4. 为什么可能「什么都没出现」

解析状态loader 行为
unbound / unknown不注入；页面 console 记一条原因（该线没绑副驾，或线 id 不合法）
closed不注入；原因可能是 agent_paused / agent_missing / agent_private / chat_not_open
ready注入 widget；anonymous: login_required 时访客会看到登录升级（文案点名平台）

静默死卡比没有入口更糟：配置缺失该在控制台看见，不该由访客承担。

5. loader 不可用时（兜底）

直连 widget 地址仍然可用——它就是 loader 注入的那个 iframe，行为完全一致，只是宿主得自己写协议。

<iframe src="https://wanxing.finddatatech.cloud/#/embed/<agentSlug>?open=1"
        style="position:fixed;bottom:0;right:0;width:420px;height:640px;border:0;
               background:transparent;z-index:2147483000"></iframe>
